# 字体安装清单

打开 PSD 编辑文字前安装以下字体；不嵌入 PSD，均已随附。

| Photoshop PostScript 字体名 | 字体文件 |
|---|---|
| `LXGWWenKai-Light` | `LXGWWenKai-Light.ttf` |
| `InriaSans-Light` | `InriaSans-Light.ttf` |
| `LXGWWenKai-Regular` | `LXGWWenKai-Regular.ttf` |
| `CormorantSC-Light` | `CormorantSC-Light.ttf` |
| `LXGWWenKai-Medium` | `LXGWWenKai-Medium.ttf` |
| `NotoSerifCJKsc-Regular` | `NotoSerifCJKsc-Regular.otf` |

另附霞鹜文楷 Light / Regular / Medium 全部三个字重。
Noto Serif CJK SC Regular 为原系统 TTC 的简体中文面（index 2）无改字形导出的独立 OTF，字体内部名称不变。
原排版脚本虽定义 Noto Sans CJK SC，但这张成稿没有实际用到，故未附带。
